# Scorciatoie

L'elenco completo, sempre aggiornato con le tue modifiche: **Super+K**. Le principali si cambiano in Impostazioni → Scorciatoie.

| Tasti | Cosa |
|---|---|
| Super (da solo), Super+Spazio | Lanciatore e Ciel |
| Super+A | Riquadro (Install, Strumenti, modelli, Guida) |
| Super+I | Impostazioni |
| Super+J | Casella di Ciel |
| Super+N | Notifiche |
| Super+L | Blocca lo schermo |
| Super+Esc | Spegni, riavvia, esci, BIOS/UEFI |
| Super+T | Terminale |
| Super+W | Browser (CielFox) |
| Super+E | CielFile |
| Super+Q | Chiudi la finestra |
| Super+F / Super+Alt+F | Schermo intero / ingrandisci |
| Super+Alt+Spazio | Finestra fluttuante o affiancata |
| Super+P | Fissa la finestra su tutti i workspace |
| Super+O | Stacca la finestra (sopra le altre) |
| Super+1…0 / Super+Alt+1…0 | Vai al workspace / mandaci la finestra |
| Alt+Tab | Finestra successiva |
| Stamp | Schermata di un'area (un clic prende una finestra, Esc annulla) |
| Maiusc+Stamp / Ctrl+Stamp | Schermata di tutto lo schermo / della finestra |
| Super+Maiusc+S | Un'area dello schermo negli appunti |
| Super+Maiusc+R | Registra lo schermo (di nuovo: ferma) |
| Super+Ctrl+R | Registra con l'audio |
| Super+Maiusc+T | Copia il testo da un'area dello schermo (OCR) |
| Super+Maiusc+C | Prendi un colore |
| Super+V | Cronologia degli appunti |
| Super+. | Emoji |
| Super+K | Elenco delle scorciatoie |
| Super+Maiusc+M | Muto |
| Ctrl+Super+Spazio | Musica: pausa |
