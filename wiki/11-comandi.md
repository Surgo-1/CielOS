# Comandi

| Comando | Cosa fa |
|---|---|
| `cielos aggiorna` | aggiorna il sistema (ondate, istantanea, ritorno automatico) |
| `cielos ritorna` | torna a prima dell'ultimo aggiornamento |
| `cielos medico [ripara [ID]]` | la visita del PC, e le riparazioni |
| `cielos segnala` | raccoglie le informazioni su un problema (e le manda su GitHub se vuoi) |
| `cielos errore "TESTO"` | cosa vuol dire un errore e cosa fare |
| `cielos wiki [pagina]` | questa guida |
| `cielos versione` | la versione di CielOS e dell'ondata |
| `cielos hardware` | cosa serve a questo PC (driver, firmware) |
| `cielos plugin …` | i plugin: elenco, installa, togli |
| `cieltema …` | l'aspetto (temi, colori, sfondo) |
| `cielimposta …` | le impostazioni di sistema (schermi, tastiera, mouse, audio…) |
| `cielstrumenti …` | gli strumenti (registra, testo, qr, colore, luce, sveglio, dns…) |
| `cielmodelli …` | i modelli di Ciel |
| `cielondate stato` | lo stato delle ondate |
| `ciel "domanda"` | chiedi a Ciel dal terminale |
| `ciel-shell-scegli ciel` | usa la shell di CielOS |

Quasi tutti hanno `--json` (per i programmi) e funzionano anche in inglese (`cielos update`, `rollback`, `doctor`, `report`, `version`).
